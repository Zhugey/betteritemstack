# BetterItemStack 物品堆叠数修改
- 基于 https://github.com/develk-coder/ItemStackProMax
- 新增可堆叠物品黑名单配置，于配置文件中添加不需要堆叠的物品id。
## Configuration

- `~/config/betteritemstack.json`

> - 在游戏中使用'/bis get'来查看当前最大堆叠数
> - 在游戏中使用'/bis set xxx'来设置最大堆叠数
